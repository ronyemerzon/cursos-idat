EDUPORTAL 3. ENRUTAMIENTO SPA

Enrutamiento Jerárquico & Lazy Loading

Optimización del rendimiento de la SPA cargando módulos solo cuando son requeridos.

// app.routes.ts (Lazy Loading & Guards)
export const routes: Routes = [
  { path: 'login', canActivate: [loginGuard], loadComponent: ... },
  {
    path: '',
    component: MainLayoutComponent,
    canActivate: [authGuard],
    children: [
      { path: 'dashboard', loadComponent: ... },
      { 
        path: 'usuarios', 
        canActivate: [roleGuard], 
        data: { roles: ['ADMIN'] },
        loadComponent: ... 
      },
      { path: 'cursos', loadComponent: ... },
      { path: 'cursos/:id', loadComponent: ... },
      { path: 'perfil', loadComponent: ... }
    ]
  },
  { path: 'unauthorized', loadComponent: ... },
  { path: '**', loadComponent: ... }
];
⚡ Carga Diferida (Lazy Loading)
Reduce el tamaño del bundle inicial descargado por el navegador en más de un 60%.
🔍 Parámetros Dinámicos (:id)
Ruta /cursos/:id para visualizar syllabus y ficha técnica en tiempo real.
🚫 Manejo 404 (Wildcard)
Ruta comodín que captura cualquier enlace no existente y lo redirige a la vista 404.

EDUPORTAL 4. GUARDS DE SEGURIDAD

Guards de Autenticación y Autorización

Blindaje de rutas contra accesos no autorizados e intrusiones.

AuthGuard
Validación de Sesión
• Verifica existencia de JWT en LocalStorage.
• Valida que el token no haya expirado.
• Redirige a /login?returnUrl=... si no hay sesión.
RoleGuard
Control por Roles
• Lee data: { roles: [...] } de la ruta.
• Si un Estudiante intenta entrar a /usuarios, lo bloquea.
• Redirección a /unauthorized (403).
LoginGuard
Evita Doble Sesión
• Si el usuario ya está autenticado, no le permite ver el login.
• Lo redirige de inmediato al /dashboard.

EDUPORTAL 5. TOKEN JWT & INTERCEPTORES

Seguridad con JSON Web Token & Interceptores HTTP

Comunicación asíncrona autenticada y control global de errores.

📦 Flujo del Token JWT
1. Login: POST /api/auth/login con correo y clave.
2. Firma: Spring Boot genera token firmado (HS256) con claims (id, email, rol).
3. Almacenamiento: Guardado seguro en LocalStorage.
4. Intercepción: Inyección automática de cabecera Authorization: Bearer <token>. 
// jwt.interceptor.ts (Inyección Bearer)
export const jwtInterceptor: HttpInterceptorFn = (req, next) => {
  const authService = inject(AuthService);
  const token = authService.getToken();

  if (token && !req.url.includes('/auth/login')) {
    const cloned = req.clone({
      setHeaders: { Authorization: `Bearer ${token}` }
    });
    return next(cloned);
  }
  return next(req);
};
